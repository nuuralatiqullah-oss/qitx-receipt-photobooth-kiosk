What guests see

This wording appears on the booth screens and is printed on every strip.

Admin PIN

Keeps guests out of this page during an event. It is stored on the tablet in plain text, so use a number you don't use anywhere else.

Strip layouts

Turn off any layout you don't want guests to pick. Photo slots run nearly edge to edge so each photo gets the most dots the printer can give it.

Upload a template

A PNG the width of the paper with see-through holes where the photos go. The holes are found for you — no coordinates to type. Design it at 576 px wide (or any width; it gets scaled). Bold artwork and plenty of white print best: the printer has no grey and no colour.

Add a plain layout

Set how many photos and the shape. Slots are placed for you across the full 576-dot width.

Not connected

Settings test prints the same photo four ways, labelled A–D, so you can pick the clearest and set Dot size to match.
Printer diagnostic prints solid blacks and a density ladder. Streaks in the same columns every time mean a dirty print head; fading towards the bottom means it's running too hot.

Paper and cutting

Photo quality

The printer is 203 dpi and every dot is black or white — there is no grey and no colour. These decide how a photo becomes dots.

Auto-fix dim or backlit photos

Print energy

If dark areas break up or streak, slow the printer down before making it darker. Leave blank to use the printer's own setting.

Supabase

Optional. Without it the booth still captures and prints — it just won't upload or show a QR code. Use the publishable key, never the secret one.

Not tested

Save first, then test. The test checks the keys, the photo bucket and the prints table, and tells you which step is missing. Once it passes, guests get a QR code to download their strip.

Start over

Puts every setting back to the defaults in the code. Your saved strips are not touched.
